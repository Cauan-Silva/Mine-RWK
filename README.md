# Mine-RWK

Mod de Minecraft com kits de personagens de anime, sucessor do Minezin, feito em **NeoForge**.

Minecraft 1.21.1 · NeoForge · Photon2 · GeckoLib · Player Animation Library.

O projeto está na fase de base: o mod compila e carrega no jogo com todas as bibliotecas, ainda sem personagens. Para compilar: `./gradlew build`; para abrir o jogo: `./gradlew runClient`.

- Documentação, decisões e diário: pasta [`vault/`](vault/) (abra no Obsidian).
- Ponto de partida: [`vault/00 Início.md`](vault/00%20In%C3%ADcio.md).
